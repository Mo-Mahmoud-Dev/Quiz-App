# Quiz App 🚀

An interactive quiz web application designed to test and assess developers' knowledge across various programming languages and tech stacks. 

---

## 🌟 Features

* **Interactive Quizzes:** Multiple-choice questions with immediate scoring and feedback.
* **Clean & Responsive UI:** Simple, user-friendly interface designed for seamless navigation.
* **Current HTML Support:** Features a dedicated question bank for **HTML**.
* **Scalable Architecture:** Built with future expansion in mind, making it easy to add new programming languages and topics.

---

## 🎯 Supported Languages & Roadmap

- [x] **HTML** (Currently Available)
- [ ] **CSS** (Coming Soon)
- [ ] **JavaScript** (Coming Soon)
- [ ] Additional languages and frameworks (Python, PHP, React, etc.)
- [ ] Timer feature for quizzes
- [ ] Detailed result summary showing correct/incorrect answers at the end of each quiz

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 & SCSS**
* **JavaScript (ES6+) & Vue.js (V3) **

## 🚀 Getting Started

To run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mo-Mahmoud-Dev/Quiz-App.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Quiz-App
   ```

3. **Run the application:**
   * Open the `index.html` file in any web browser (Chrome, Firefox, Edge, etc.).
